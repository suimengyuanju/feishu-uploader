# 飞书云文档工具

一个 Python GUI 工具，支持批量上传文件到飞书云空间和多维表格。

## 功能

### 文件上传
- 上传文件/文件夹到飞书云空间
- 支持所有常见文件类型（文档、图片、视频、音频、压缩包）
- 大文件自动分片上传（>20MB）
- 网络中断自动重试

### 多维表格
- **手动填写** — 根据表格列自动生成输入表单
- **Excel/CSV 导入** — 自动匹配列名，支持映射调整
- **文件夹批量上传** — 每个子文件夹 = 一行数据，自动匹配文件到对应列

#### 文件夹上传工作流
```
父文件夹/
  ├── 项目A/          → 第1行
  │   ├── video.mp4   → video 附件列
  │   ├── preview.png → preview 附件列
  │   └── prompt.md   → prompt 文本列（读取内容）
  ├── 项目B/          → 第2行
  │   ├── video.mp4
  │   ├── preview.png
  │   └── prompt.md
  └── ...
```

- 自动按文件名匹配表格列（去扩展名后与列名比对）
- 同扩展名自动模糊匹配（如不同编号的 zip 文件）
- 支持按压缩包编号、修改时间、自然排序等方式排序
- 自动排除空文件夹、隐藏文件夹、无匹配文件的文件夹
- 支持追加/更新模式 + 指定起始行
- 上传日志写入文件，方便排查

## 安装

```bash
pip install -r requirements.txt
```

依赖：`requests`, `openpyxl`（可选，Excel 导入用）

## 使用

```bash
python feishu_uploader.py
```

## 飞书应用配置

1. 在 [飞书开放平台](https://open.feishu.cn/app) 创建企业自建应用
2. 开通权限：`bitable:app`, `drive:drive`, `drive:file:upload`
3. 发布应用
4. **将多维表格分享给应用**（右上角分享 → 搜索应用名 → 可编辑）
